Technical Deep Dive: WebRTC IP Leaks and STUN/TURN Discovery

WebRTC is the open framework powering real-time video streaming across modern browsers. However, WebRTC incorporates interactive connectivity establishment (ICE) protocols that query STUN (Session Traversal Utilities for NAT) and TURN servers to determine the shortest network path between endpoints.

This creates a significant vulnerability for users relying on low-quality VPNs:

  1. STUN Request Bypass: Even when standard HTTP traffic is routed through a VPN interface, a WebRTC JavaScript call can dispatch UDP binding requests that directly query local default gateways.
  2. IP Exposure: The STUN server responds with the client's public residential IP address, bypassing the VPN tunnel entirely.
  3. Prevention Tactics: To seal WebRTC leaks, users should disable non-proxied UDP in browser settings (e.g., `media.peerconnection.ice.default_address_only` in Firefox) or use native leak-shielded VPN applications with integrated firewall kill-switches.
